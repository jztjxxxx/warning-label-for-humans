A one-line safety warning label for human beings, written for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty. The program in this repository writes the label to `/output/entry.txt`:

> WARNING: This human runs on six hours of sleep, three coffees and one unread email from 2023. Do not shake, do not update.

## Run it

```sh
node main.ts
```
